# ClinScribe Preview

A clinical scribe showcase with a credential-free sample demo and optional live AI generation.

## Run locally

Run npm install, then npm run dev. Open http://localhost:3000 and choose Run Demo. No AWS credentials are required for the sample demo.

## Modes

- Demo streams one of three fictional consultations, then streams a prepared sample note. Finish the complete consultation before generating its note. Choose GP note, specialist referral, or ED triage. Notes can be edited and copied. Sample notes are clearly labelled and are not generated by AI.
- Live transcribes microphone speech using the browser Web Speech API (Australian English), then calls Claude Opus 4.6 through AWS Bedrock. Set AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY and AWS_REGION in .env.local or your hosting environment. Missing credentials return an unavailable response; failed AI requests direct visitors to the sample demo. Use Home to switch modes.

## Implementation

Next.js 16, React 19, TypeScript, Tailwind CSS 4 and Vercel AI SDK 6. Both generation paths use the same section sentinel protocol and client parser. Demo requests are validated against the complete sample transcript and never call Bedrock. Credentials are validated only for live requests.

State lives in useWorkspace using React reducers. There is no authentication, database, saved patient record or EHR integration.

## Checks

- npm test
- npm run lint
- npm run build

Live mode is disabled by default. After verifying working Bedrock access, set LIVE_AI_ENABLED=true along with all three AWS variables. The server passes only an availability boolean to the UI; credentials stay on the server. Both the landing button and live API enforce this setting.
